1. Size of the cache at each level. Copied and pasted from $(lscpu)
L1d:                    768 KiB (16 instances)
L1i:                    512 KiB (16 instances)
L2:                     32 MiB (16 instances)
L3:                     36 MiB (1 instance)

L1d has 48Kib per core, the L1i has 32Kib per core, L2 has 2Mib per core and the L3 is 36Mib all shared.
The virtual machine I am using uses 39-bit physical addresses and 48-bit virtual addresses.

The three common file types are a text file which is expected to be about 10Kib to 1 Mib, a JPEG which is about 2Mib to 8Mib,
and an MP4 which is usually over 100Mib up to a Gib. The txt file and JPEG will fit into the 36MB L3 cache but the MP4 won't.
This means the CPU will be placed in memory instead of the caches.
Which will take longer to retrieve because it has to be wrote to main memory and then it will have to be retrieved.


2. Choose an arbitrary address (within the address size of your machine) to use as the starting address for your arrays. Describe your choice of cache layout (Direct, SA, FA).

My starting address is 0x10000000 and I am choosing direct mapped for simplicity.
Direct mapped is simpler because each block of mempory will map to one cache line which is  based on the index of bits. The index portion of the address will show which cache line is being accessed. This will then compare the tage to determine if the access was a hit or a miss. 

For this assignment I am using a cache size of 4096 bytes and a block size of 64 bytes which results in 64 cache lines.
